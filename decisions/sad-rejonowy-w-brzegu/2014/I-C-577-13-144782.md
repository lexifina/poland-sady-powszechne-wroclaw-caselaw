# Sąd Rejonowy w Brzegu, Wyrok, 2014-01-27, I C 577/13

## Teza

brak dowodów potwierdzających zasadność roszczenia

## Treść

Sygn. akt I C 577/13 upr.

Na rozprawie dnia 27 stycznia 2014 r.

Stawił się: Powód nie stawił się, zawiadomiony
